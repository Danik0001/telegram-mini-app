Дата: 15.10.2026. Сначала открыть README.md и MVP_TRACEABILITY.md.

## Исходники и система

`design-manifest.json` — контент и структура экранов; `design-data.js` — те же данные для браузера; `prototype.js` — логика демонстрации; `prototype.css` — компоненты и адаптация; `tokens.css` — вынесенные основы. Изменения необходимо синхронизировать с автономным HTML. Для production требуется перенос в архитектуру приложения и подключение реальных сервисов.

Базовый интерфейс 390 px; внешняя панель просмотра в продукт не переносится. Цвета: фон #101110, surface #1b1d1b, текст #f5f2e9, вторичный #afb4a7, действие #dfbc78 с текстом #161710, ошибка #f0a5a5. Отступы кратны 4; основной ритм 8/12/16/24/32. Разделять карточки поверхностями и тонкой границей. Золото использовать для выбранного состояния и главного действия. Читаемый системный sans-serif; окончательный брендовый шрифт согласовать отдельно. Не уменьшать touch targets ради декоративной плотности.

Состояния компонентов: default/selected/disabled/loading/error. Основные семьи: button, input/select/textarea, segmented control, карточка каталога, player, track rack, mixer channel, FX row, alert, navigation, external link. Текст состояния не должен передаваться только цветом. Для иконок — aria-label; для результатов — live region. Focus-visible и управление клавиатурой сохраняются.

## Встраивание Telegram

- Использовать реальные Telegram viewport/safe-area параметры; учитывать нижний inset и клавиатуру, не перекрывать основное действие навигацией.
- Связать BackButton и закрытие с текущим шагом. При записи или несохранённом вокале показать предупреждение; не обещать сохранение проекта.
- На мобильном оставить пять нижних вкладок. На широком экране студию распределить по колонкам, сохранив порядок записи → FX → микс → экспорт.
- Подключать микрофон только по действию пользователя. Обработать отказ, отмену, обрыв и лимиты. Не показывать успешный дубль до подтверждения сервиса.
- Генерация и обработка должны отражать реальный статус задания. При retry не дублировать платное/квотируемое действие. Не выдумывать процент готовности.
- Экспорт: настоящий full-mix WAV, фактические параметры из backend. Результат экспорта не меняет права на инструментал.
- Wallet: TON Connect, disconnect, ASIQ balance/refresh; неизвестный баланс показывать прочерком. Адрес сокращать только визуально; подтверждение подключения и транзакции выполняет реальный кошелёк. STON.fi открывать как внешний сервис после информационного экрана.
- Community: подставить подтверждённые официальные URL; не превращать раздел в неподтверждённую социальную сеть.

## Импорт в Figma

Создать страницы Foundations, Components, Screens, Adaptive, Flows. Перетащить SVG из `figma-import/`; каждый содержит отдельные векторы и текст. Начать с ui-kit.svg, затем music/library/studio/record/process/samples/wallet/community, после — состояния. PNG использовать для сравнения.

SVG — переносимый редактируемый материал, но не готовая нативная библиотека Figma. Нужно назначить Auto Layout, constraints, local variables и text styles; собрать component variants, заменить повторения instances и связать prototype connections по IA_FLOWS.md. При смене шрифта проверить переносы. Старый файл Figma остаётся v1 и не является источником v2.
