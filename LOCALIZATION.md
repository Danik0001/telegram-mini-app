# Локализация и контент

Рабочая версия интерфейса — русский с сохранением названий продукта/инструментов Music, Library, AI Studio, Wallet, Community, MID/BACK/ADLIBS и FX. Полный перевод на казахский/английский не выполнен. Название трека «Әңгіме» сохранять как оригинал. Раскладка рассчитана на изменение длины текста; перед выпуском проверить каждый язык и длинные строки.

| Смысл | RU — текущий | EN — предложение |
|---|---|---|
| Начало записи | Записать выбранную дорожку | Record selected track |
| Обработка | К обработке | Continue to processing |
| Экспорт | Скачать WAV | Download WAV |
| Потеря сессии | До закрытия сохрани WAV | Download WAV before closing |
| Баланс неизвестен | Подключите TON-кошелёк | Connect a TON wallet |
| Ошибка сети | Проверь подключение и повтори | Check connection and retry |

В production вынести все строки в i18n-ключи. Числа/длительности форматировать локалью; идентификаторы TON и названия валют не переводить. Значения BPM/KEY/лимитов получать из сервиса. Не писать «сохранено» без подтверждённого постоянного хранения, «готово» до окончания задачи, «баланс 0» при ошибке получения.
